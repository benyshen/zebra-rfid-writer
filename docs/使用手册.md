# 使用手册（操作员版）

面向产线/仓库操作人员：从打开软件到把一批标签写完的完整流程。

---

## 1. 启动

双击 `RfidWriter.exe`（`bin\Release\` 目录下，需与 `Symbol.RFID3.Host.dll`、`rfidapi32pc.dll` 同目录）。

> 只支持 64 位 Windows；无需安装 .NET，机器上是 Windows 10/11 即可（自带 .NET Framework 4.8）。

---

## 2. 连接读写器

### 2.1 先判断读写器的 LLRP 角色

打开读写器 Web UI（`https://读写器IP`）→ LLRP 页面，看 `Operating Mode`：

| Web UI 显示 | 说明 | 本程序怎么设 |
|---|---|---|
| `Client` | 读写器主动往外连（每约 2 秒重试一次），不监听端口 | 连接方式选第一项「读写器主动连入（监听模式）」，端口填**本机**等待端口（默认 5084） |
| `Server` | 读写器监听端口，等主机来连 | 连接方式选第二项「本机主动连接读写器」，IP 填读写器地址、端口 5084 |

本机现场（FRX90）为 `Client`，Web UI 里目标 host 为 `192.168.100.13`、端口 `5084`。

### 2.2 连接

1. 连接方式选对
2. **IP 地址**：
   - 监听模式：填读写器 IP 表示"只接受这台连入"，**留空表示接受任意读写器**
   - 主动模式：就是读写器地址
3. 端口默认 `5084`
4. 点「连接」，状态变绿 `已连接：192.168.100.22` 即成功，下一行显示读写器信息（型号/固件/天线数/功率档位）

> 断开不用管：中途掉线时状态变橙色「读写器已断开，等待重新连入 ...」，读写器会自动连回来，**不需要重新点连接**。

---

## 3. 设置天线功率（建议先做）

右上方 `天线功率 [29.2] dBm ☑全部天线 [应用功率]`

- 功率越低读得越近，可避免串读隔壁货架/远处无关标签
- 勾「全部天线」= 6 根一起设；取消则只设天线 1
- 点「应用功率」后，右侧「当前 A1=15dBm A2=15dBm …」显示实际回读值
- 现场实测参考：29.2 dBm 满功率读 56 个 → 15 dBm 只读 10 个

---

## 4. 盘点读标签

点「开始盘点」，标签逐个出现在列表：序号 / EPC / 天线 / RSSI / 次数 / 写入状态；右上显示「标签总数」「已写入」。

- 读完点「停止盘点」
- 列表就是待写目标清单，**写入按这个顺序逐张进行**
- 想重新开始一次干净的盘点，点「清空列表」
- 右键单行：复制 EPC / 还原该标签为原始 EPC
- 「导出 CSV」把当前列表存成文件，便于核对或存档

---

## 5. 设置序列化规则

| 控件 | 含义 | 例子 |
|---|---|---|
| 目标存储区 | EPC 区 / USER 区 | EPC 区 = 改标签身份；USER 区 = 改用户数据区，EPC 不变 |
| USER 起始字 | 仅在 USER 区生效，单位是"字"（1 字 = 2 字节） | 0 = 从 USER 区开头写 |
| 前缀(HEX) | 固定前缀 | `E280` |
| 起始值 | 第一个序列号的数值 | `1` |
| 进制 | 数值按 16 或 10 进制表达 | 16 进制 |
| 位数 | 数字不足时左补 0 到几位 | `12` → `000000000001` |
| 步进 | 每换一个值加几 | `1` |
| 后缀(HEX) | 固定后缀 | `0000` |
| 数值编码 | HEX 原样 / ASCII 字符 | 一般用 HEX 原样 |
| 写入张数 | 本次总共写多少张标签 | `100` |
| **重复** | **同一个序列号连续写几张标签**（1 = 每张都不同） | `2` → 第1~2张同值、第3~4张同值… |
| 重试 | 单张写入失败自动重试次数 | `2` |
| 访问密码 | 标签已加密时才需要，8 位十六进制 | `00000000` |
| 写入后校验 | 写完立刻回读比对 | 建议保持勾选 |

预览框实时显示第 1 张（或第 1~N 张）将要写入的数据，先看一眼再动手。

---

## 6. 开始写入

点「开始写入」。程序逐张改写，每张的状态实时显示在列表"写入状态"列：`写入中 ... / 已写入 EPC → 0000… / 失败：原因`。

- 底部进度条 + 「写入结束：成功 N 张，失败 M 张」
- 中途点「停止写入」会写完当前这张后停下
- 中途掉线会显示"等待读写器重连 ..."，最多等 20 秒，连上后自动继续
- EPC 写入成功后，列表里的 EPC 会更新成新值（标签身份已变）

---

## 7. 出错怎么办

| 现象 | 处理 |
|---|---|
| 状态橙字「等待重新连入」 | 正常自动恢复，等 2~5 秒 |
| 一直连不上 | 确认读写器 IP 与 IP 栏是否一致（填错 IP 会被过滤掉）、端口是否被别的程序占用（同一端口只能一个程序监听） |
| 某张「失败：Tag not found in the field」 | 该标签离开天线范围了，重新靠近或改成单张重写 |
| 某张「失败：Tag write failed」 | 重试次数加大（3~5），或降低功率/调整标签位置减少干扰 |
| 写错了想撤销 | 右键该行「还原该标签为原始 EPC」（程序记录了每个标签首次读到的 EPC）；也可用命令行 `--restore` |
| 提示「生成数据 X 字节，超过该标签 EPC 容量 Y 字节」 | 序列号太长，缩短位数或改 USER 区 |

---

## 8. 两条硬规矩

1. **不要改 EPC 长度**：默认按标签原有长度自动补零；"允许改变 EPC 长度"只在高风险场景勾选，写短后再写长可能失败并留下脏 EPC。
2. **重复写 EPC = 多张标签变成同一个身份**，之后无法按 EPC 区分/单独还原。要「多张同内容」建议把批次数据写 **USER 区**，EPC 保持唯一。
